# CHIQUEHELITA

Loja virtual da CHIQUEHELITA — moda feminina.

## MVP

- Home responsiva
- Catálogo inicial
- Vestido Alice
- Seleção de tamanhos
- Carrinho
- Finalização via WhatsApp
- Publicação automática no GitHub Pages

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
