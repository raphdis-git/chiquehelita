# CHIQUEHELITA

Loja virtual da CHIQUEHELITA — moda feminina.

## MVP

- Home responsiva
- Catálogo inicial
- Vestido Alice
- Seleção de tamanhos
- Carrinho
- Finalização via WhatsApp
- Publicação automática no GitHub Pages

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

O projeto é publicado automaticamente pelo GitHub Actions sempre que há uma alteração no `main`.
